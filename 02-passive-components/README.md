# 无源器件选型与应用

整理电阻、电容、电感和磁珠的选型与应用知识，关注额定参数、频率特性、去耦与旁路、滤波效果以及常见使用问题。

## 网页笔记

[查看 HTML 文件](./index.html)。下载后用浏览器打开即可阅读，样式、图示和交互均包含在单个文件中，无需安装依赖。

点击电阻、电容、电感或磁珠按钮，可切换到对应板块。

| 板块 | 当前内容 |
| --- | --- |
| 电阻 | 阻值、封装、功率与精度，0 Ω 电阻在高速信号调试中的作用 |
| 电容 | 作用与等效模型、阻抗—频率图、滤波与 ESR、频率选型、常见类型、去耦与旁路 |
| 电感 | 框架占位，待补充 |
| 磁珠 | 框架占位，待补充 |

网页中的阻抗曲线为定性示意；具体选型应结合器件数据与实际电路条件。
