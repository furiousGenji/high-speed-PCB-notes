01 / APPLICATION NOTES

电阻应用的四个关注点

从阻值、封装尺寸、额定功率和精度四个方面检查选型。

阻值 · 满足功能与供货需求

先按电路要求计算阻值，再选择常用系列。遇到不常用的阻值，可评估用常见电阻串联或并联实现，同时核算误差、功耗和占板面积。

363 Ω = 330 Ω + 33 Ω

这是标称值组合示例，实际阻值仍受各电阻容差影响。

封装 · 区分英制与公制

相同的四位代码可能使用不同单位。核对器件手册与 PCB 封装库，不能只凭“0603”选封装。

常见英制 / 公制封装对应关系

功率 · 留出降额余量

串在高功耗路径上的电阻容易被忽略。用电阻上的实际电压或电流计算耗散功率，再检查额定功率与温度降额曲线。

P = I²R = V² / R

学习基线：至少预留 20% 的降额，即工作功耗不超过适用额定功率的 80%。高温、脉冲及散热条件还需按器件规格进一步核算。

精度 · 直接影响设定参数

当电阻用于设定电源输出等工作参数时，应按系统误差预算选择精度。以 LT3080 的简化关系为例：

VOUT ≈ RSET × 10 μA

只考虑电阻容差，±5% 对应约 ±5% 的输出偏差，最大与最小值的总跨度为标称值的 10%；±1% 对应约 ±1% 的偏差，总跨度为 2%。

这不是输出纹波，也不包含设定电流误差、温漂等其他误差。1% 是否足够仍取决于电路要求。

KEY TAKEAWAYS

理解要点

  1. 0 Ω 电阻有工程价值：可用于连接配置、隔离调试和预留串联调节位置。
  2. 高功耗路径核算额定功率：不能只看阻值，还要看发热、温度和降额。
  3. 参数设定关注精度：电阻容差会传递到器件的工作参数中。
02 / WORKED EXAMPLE

0 Ω 电阻，对高速信号有什么意义？

下面是用于理解原理的假设设计例子，数值不是某款器件的推荐配置。

例子：给一条单端时钟线留下调试余地

假设时钟驱动器输出阻抗约为 18 Ω，PCB 走线特性阻抗为 50 Ω，接收端为高阻输入，且边沿足够快、走线足够长，需要按传输线处理。在驱动端附近预留一个串联电阻焊盘，初版先装 0 Ω。

换装 33 Ω18 + 33 ≈ 51 Ω接近 50 Ω 走线阻抗，有助于吸收返回源端的反射，减轻反复反射造成的振铃。

串联匹配的估算：R ≈ Z₀ − ROUT = 50 − 18 = 32 Ω → 评估常用值 33 Ω

0 Ω 的意义在于可调整的连接位置。若实测波形和时序已满足要求，可以保留 0 Ω；若有过冲、下冲或振铃，可在同一位置更换适当阻值，再检查接收端波形与时序裕量。焊盘应靠近信号源，并避免分支残桩。

实物 0 Ω 电阻有有限的直流电阻及寄生参数；焊盘也会引入不连续。它不是理想导线，也不能保证改善高速信号。选型需核对电流规格；超高速差分接口应遵循对应接口与芯片的布局、端接规范。

扩展依据：SiTime AN10002 · 单端时钟串联端接；Vishay · 电阻额定参数与高频特性。数值例子为基于端接原理的演算。

2.2.2 / FUNCTION & MODEL

电容的作用与等效模型

理解实际电容，要同时考虑储能作用、寄生参数及其随频率变化的阻抗。

三个主要作用

  • 电荷缓冲：通过储存和释放电荷，支撑负载瞬态电流，减小供电电压变化。
  • 高频噪声回路：在适用频带内，为噪声提供低阻抗回流通路，降低电源干扰。
  • 交流耦合：隔离收发两端的直流偏置，同时传递所需交流信号；容量选择要满足信号低频成分及接口要求。
ΔV = ΔQ / C
ZC,ideal = 1 / (jωC)，ω = 2πf

理想电容公式不能覆盖实际器件在全部频段的表现。

实际电容包含哪些参数？

参数含义与影响
C有效电容量，决定储能与容性阻抗。
ESL等效串联电感，与结构、封装及安装连接有关，限制高频性能。
ESR等效串联电阻，随频率、温度及材料等变化，影响损耗和最低阻抗。
Rleak等效并联漏电阻，表征电容的漏电通路。

选型不能只看 μF 值，还要看工作频段下的阻抗与器件规格。

读懂阻抗—频率曲线

  • 自谐振频率以下：容性为主，频率升高时阻抗通常下降。
  • 自谐振附近：C 与 ESL 的电抗抵消，简化串联模型中的阻抗最低，约由 ESR 决定。
  • 自谐振频率以上：感性为主，ESL 使阻抗随频率上升。
fSR ≈ 1 / (2π√(ESL × C))

这里 f 为 Hz；角频率关系为 ωSR = 1 / √(ESL × C)。

容量与封装需要一起搭配

  • 目标是在噪声频带内保持足够低的阻抗，而不是单纯增加标称容量。
  • 小封装、短电流路径及反向几何结构可用于降低 ESL；具体数值应查器件资料。
  • 相同电容并联可提高总容量并降低阻抗，但不等于低阻抗频带一定拓宽。
  • 不同电容的组合需同时比较容量、ESL、ESR 与安装条件，不能只按“大容量管低频、小容量管高频”判断。
FILTERING / ESR / FREQUENCY

滤波电容：让目标频带内的阻抗足够低

滤波效果取决于电容所在的完整电路。容量只是其中一个参数，还需结合噪声频带、ESR、ESL、供电网络和回流路径判断。

滤波电容如何起作用？

电源与地之间的滤波电容，为交流噪声电流提供局部低阻抗回路，并通过储存、释放电荷减小电压波动。它与电源及连接路径的阻抗共同决定噪声如何分配。

  • 储能角度：关注负载变化所需电荷，以及允许的电压变化。
  • 频域角度：关注整个电源网络在噪声频带内的阻抗，而非单一频率下的容量。
  • 布局角度：缩短电容、供电引脚及回流路径组成的回路，降低安装电感。
ΔV ≈ ΔQ / C
Ztarget ≈ ΔVallow / ΔI

目标阻抗是初步设计指标；实际瞬态还受 ESR、电感、供电控制环路及电流变化速度影响。

选型与验证顺序

  1. 明确允许的电压波动、负载电流变化和需要抑制的噪声频带。
  2. 以工作偏压、温度和容差下的有效容量评估储能需求。
  3. 查看阻抗—频率曲线，核对 ESR、ESL 和自谐振频率。
  4. 结合布局、过孔与参考平面，评估安装后的网络阻抗。
  5. 检查稳压器对容量、ESR 的要求，以及纹波电流、极性和降额条件。

器件本身低阻抗，并不代表焊接到 PCB 后仍能在同一频带保持相同效果。

ESR 的代价：损耗与电压波动

  • 发热：纹波电流流经 ESR 会产生损耗；简化估算为 P ≈ Iripple,rms² × ESR。
  • 瞬态压差：电容电流改变时，ESR 带来约 ΔVESR ≈ ΔIC × ESR 的电压变化。
  • 最低阻抗：在简化串联模型中，自谐振附近的最低阻抗主要由 ESR 决定。
  • 交流耦合：ESR 是信号通路中的额外串联损耗，可能增加衰减。

因此，在满足稳定性等条件时，较低 ESR 通常有利于降低供电阻抗与损耗。

ESR 的作用：稳定性与阻尼

ESR 不是越低越好。部分稳压器会利用输出电容的 ESR 形成零点，参与控制环路补偿。ESR 超出允许范围时，即使容量足够，也可能出现稳定性问题。

fzero ≈ 1 / (2π × ESR × C)
  • 按具体稳压器手册核对输出电容容量及 ESR 的允许范围。
  • 检查 ESR 随频率、温度的变化，不能只比较一个标称值。
  • 适当的损耗也可为谐振网络提供阻尼；过度追求低 ESR 可能让阻抗峰更尖锐。

ESR 零点的作用取决于控制架构；不能将某一稳压器的要求推广到全部电源。

RULE OF THUMB / LIMITS

“低频噪声选大电容，高频噪声选小电容”怎么理解？

这是简化的选型经验。它在只看容量时容易理解，但实际应用还必须考虑封装与寄生参数。

低频选大容量：储能与容性阻抗

在容性区，同一频率下 C 越大，理想容抗 1 / (2πfC) 越小；较大有效容量也能提供更多电荷储备。因此，大容量器件常承担较慢负载变化的储能和较低频滤波。

前提是器件在目标频段仍有合适的阻抗，且容量、纹波与温度性能满足要求。不能只凭“容量大”判定整个频段的滤波能力。

高频选小容量：关键是 ESL 与安装

当 ESL 相同时，减小 C 会提高自谐振频率。但在远高于自谐振的感性区，阻抗近似为 2πf × ESL，主要取决于 ESL，而不是容量。

小容量并不自动等于高频性能更好。如果封装和 ESL 接近，小容量电容不一定优于大容量电容；更低 ESL 的结构、较小回路和合理安装往往更关键。

并联：不能只看容量组合

  • 同型号并联：理想情况下可增加容量、降低等效阻抗；自谐振频率不因数量增加而必然提高。
  • 不同器件并联：可能覆盖不同频段，但需联合考虑容量、ESL、ESR 与安装参数。
  • 检查反谐振：并联网络中，一支路呈感性、另一支路呈容性时，可能出现额外的高阻抗峰。

是否拓宽了低阻抗频带，应看组合后的网络阻抗，不能仅凭“大、小电容各放一颗”判断。

更可靠的选择原则

低频侧重有效容量，高频侧重低电感，全频段检查网络阻抗。

  • 大容量负责储能是否充足，小回路负责快速电流能否及时流动。
  • 用阻抗曲线判断目标噪声频带是否被覆盖。
  • 同时核对稳压器稳定性与并联网络的谐振峰。
  • 最终结合器件资料、仿真或测量确认效果。

扩展阅读：TI · 输出电容 ESR 与稳压器稳定性；Murata · 电容并联与反谐振。

DATASHEET CHECKLIST

电容手册应核对的参数

尺寸与料号、额定电压、有效容量、ESR 的测试频率与温度、额定纹波电流、损耗角正切 tan δ，以及漏电流。

ESR 并非越小越好：低 ESR 通常有利于降低损耗和供电阻抗，但部分稳压器对输出电容 ESR 有稳定性要求，必须满足芯片规定的范围。

额定纹波电流描述规定条件下的交流电流承受能力，不能直接当作浪涌电流额定值。

2.2.3 / TYPES & SELECTION

常见电容及应用要点

按极性、有效容量、频率特性、温度表现和瞬态承受能力选择，并结合具体器件数据。

四类常见器件的学习对照
类型主要特点应用关注点
陶瓷电容无极性，贴片结构通常有较低 ESR / ESL，适合局部去耦与高频旁路。介质类别、温度特性、直流偏压下的有效容量及封装。
钽电容有极性，可提供较大容量，适用于相应频段的储能和滤波。严格核对电压降额、极性、浪涌与上电条件，尤其注意低源阻抗和热插拔。

陶瓷介质：稳定性有差别

X7R−55～+125 °C规定条件下约 ±15%。

温度特性代码不代表初始容差，也不保证直流偏压下仍有标称容量。

按有效容量做设计

  • 标称容量是在规定测试条件下得到的值，工作电压和温度改变后，有效容量可能下降。
  • X7R、X5R 仍需检查直流偏压特性；Y5V 的变化更大，不宜依赖其标称值保证高速电路去耦。
  • 资料中的“至少留 20% 余量”可作为学习起点，但不能替代对具体器件容量曲线的检查。
  • 以最不利工作条件下的有效容量核对电路需求，同时预留容差与老化余量。

钽电容：重点控制瞬态应力

  • 电压降额和浪涌能力是选型重点，不能因 ESR 低、容量大而忽略可靠性。
  • 资料对传统钽电容提出较保守的降额思路：一般工作电压不高于额定值的 50%；强感性、低串联阻抗或大瞬态条件下，进一步降至约 30% 或以下。
  • 这些比例须结合具体技术路线和厂家要求判断；热插拔、上电、测试与老化过程都需要检查。
  • 同时权衡容量、ESR、耐压、面积和成本。

铝电解与 OS-CON：关注温度和寿命

  • 液态铝电解在低温下 ESR 可能明显升高；高温和纹波发热会影响寿命。
  • 随老化，有效容量可能下降、ESR 可能增大，需评估全寿命内的滤波能力。
  • 铝电解的电压余量也需检查，资料给出的至少 20% 降额不能替代温度、纹波与寿命评估。
  • OS-CON 的低 ESR 特性可用于相应电源滤波，但需确认稳压器稳定性及具体规格兼容。
2.2.4 / DECOUPLING & BYPASS

去耦电容与旁路电容

这两个名称描述电容的用途，不是两种不同的电容材料或器件类型。

去耦 · 支撑本地负载

  • 作为器件附近的本地电荷储备，快速补充负载变化所需的瞬态电流。
  • 为器件自身产生的高频电流提供局部回路，减轻其对共用电源及其他负载的影响。
  • 重点关注电源引脚附近的布置和完整电流回路的低阻抗。

旁路 · 分流外来噪声

  • 为前级电源等带来的高频噪声提供低阻抗通路，减少噪声进入被供电器件。
  • 在适用频带内将干扰电流引向参考地回路。
  • 同一颗电容可以同时承担旁路与去耦作用，两者没有严格的器件边界。
KEY TAKEAWAYS

电容选型的核心顺序

  1. 先明确用途：储能、滤波、去耦、旁路或交流耦合。
  2. 再看工作条件：电压、温度、噪声频带、纹波与瞬态电流。
  3. 核对真实器件：有效容量、ESR、ESL、极性、封装、降额及寿命。
  4. 最后检查安装效果：结合布线和回流路径评估整个网络的阻抗。
